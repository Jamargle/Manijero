# Archive

Historical records kept for traceability. Nothing here describes current behavior or status; start
from [AGENTS.md](../../AGENTS.md) for that.

- [MasterPlanV3.md](MasterPlanV3.md): the original MVP plan, research, and decision register.
- [build-brief.md](build-brief.md) and [technical-discovery.md](technical-discovery.md): the discovery baseline.
- [specs/](specs/): appendices of accepted features (repository research, implementation plan,
  validator checklist, and raw feature evidence). Each feature's contract stays in
  [docs/specs/](../specs/) and its acceptance record in [docs/validations/](../validations/).

When an accepted feature is reopened, `git mv` its appendix back to `docs/specs/` first.
