## Residual limits and validator notes (non-blocking)

- Publication references are matched only when the bulletin is spelled out (`Boletín Oficial del Estado`, `Boletín Oficial de la Junta`). The acronym forms are not a bulletin reference: `Publicado en el BOE núm. 236, …` and `Se publica en el BOJA núm. 10, …` are reported `ambiguous` (review-required), and a bare `BOE núm. 236, …` line emits no publication signal. Publication never links sources or gates anything except through `ambiguous_signal`, so this does not let a change pass unreviewed; the limitation sections say "bulletin names" and could be read as covering the acronyms. A later documentation touch should say the bulletin name must be spelled out.
- Negation is sentence-scoped, so a sentence that mixes an action with an unrelated negation (`El presente real decreto se modifica sin que se altere el plazo.`) is classified `negated_signal`/`ambiguous` with no target link. The sentence still forces `ambiguous_signal`, so review is preserved; the appendix records the sentence-scoped rule.
- The defensive CLI catch prints `{"error": "<ExceptionType>"}` rather than one of the fixed error names. That path is unexercised by tests and leaks no path, document value, or personal data; every validated failure still prints only the fixed name.
- No live run against a real published amendment exists; detection precision/recall remain unmeasured and no legal-coverage or answer-quality claim follows from this acceptance.

## Security assessment

Feature-scoped review found no blocking issue. The command runs locally with no network access and no credentials; it validates ingestion state, catalog, passage set, case set, and per-block quarantine documents at the boundary, confines quarantine paths to `<candidate_id>/…` with no `..` or absolute paths, and fails closed before writing on invalid global input. Report content is bounded official-document excerpts plus identifiers, so no personal or land data is introduced (test `test_report_omits_land_data_and_attempt_history`). Failure output is fixed-value only, and the knowledge-directory write guard was reproduced. Residual risks are operator-side: the quarantine is trusted local input and reporting is unrestricted outside `knowledge/`.
