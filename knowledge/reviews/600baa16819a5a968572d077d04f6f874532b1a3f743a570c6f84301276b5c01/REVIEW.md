## Limits

- Preparation verifies the extracted-text digest and, when the original bytes are still present in the quarantine, the original-bytes digest. A missing original copy is reported as a reviewer question; only a person can compare the extracted text with the official original.
- Evidence retention follows the operator's ingestion state and quarantine. Neither is garbage-collected, and deleting either makes an old package's evidence unrecoverable.
- Review display is bounded: text diffs, signals, and proposed field changes show at most a fixed number of excerpts and characters. A large document must be opened in the quarantine for a full reading.
- Extraction supports standard-library PDF/HTML text without OCR. Scanned, encrypted, or unsupported documents were already failed or uncertain at ingestion; this package inherits that limitation.
- A proposal that changes the reviewed corpus requires the reviewed answer-evaluation case set. Preparation validates the after-state catalog and passages against those cases, and a case that would lose an expected source or passage blocks readiness with the affected case ids. Without a case set, any catalog or passage change is blocked; a no-op proposal is still allowed.
- Merge revalidates the same case set by digest before writing canonical files, so editing the cases after preparation cannot bypass preparation's after-state check. Evaluation cases are not rewritten or retired by this feature; a reviewer must update them in a separate reviewed change.
- Affected and rewritten answer-evaluation cases are reported, not re-run, and every metric stays report-only. A human approval of this bounded update is not legal completeness, corpus currency, or answer-quality certification.
- Canonical catalog/passage after hashes and merge writes preserve each file's existing field order; only a real proposal change alters the diff. A no-op package leaves both canonical files byte-identical.
- Review turnaround and reviewer availability are operational, not automated: an unapproved package simply stays unmerged, and nothing expires it.
